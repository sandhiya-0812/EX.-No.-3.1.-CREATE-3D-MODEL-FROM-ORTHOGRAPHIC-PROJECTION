# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:10/11/2026
## Name:SANDHIYA. G
## Reg.No.:26009640

## AIM:
To create a three-dimensional solid model from the given orthographic projections using computer-aided design (CAD) software. The main aim is to understand the conversion of two-dimensional engineering drawings into a three-dimensional object by interpreting the front view, top view and side view.

This experiment helps to develop practical knowledge of 3D modelling techniques, sketching tools, solid modelling commands and dimensioning methods. It also helps to understand the shape, size and geometrical features of an object through its different orthographic views.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
Step 1: Starting the CAD Software

First, switch ON the computer and open the required CAD software, such as Autodesk Fusion 360 or SolidWorks. Wait until the software is completely loaded. Select the New Design option to create a new modelling file.

Step 2: Studying the Orthographic Projection

Observe the given orthographic drawing carefully. Identify the front view, top view and side view of the object. Study the dimensions and understand how the different views are related to each other.

Step 3: Identifying the Dimensions

Note down the overall dimensions of the object, including length, breadth and height. Identify the dimensions of additional features such as holes, slots, steps, curves and inclined surfaces. These dimensions are important for creating an accurate 3D model.

Step 4: Selecting the Working Plane

Choose a suitable reference plane such as XY, YZ or XZ plane according to the given drawing. The selected plane acts as the base for creating the initial 2D sketch.
![image](https://user-images.githubusercontent.com/113594316/198551199-8d9b7f6c-6ea7-4d59-8e8c-173f2b5e088f.png)

Step 5: Creating the 2D Sketch

Select the Sketch option and start drawing the basic profile of the object. Use suitable sketching tools such as Line, Rectangle, Circle, Arc and Polygon to create the required shape.

Step 6: Applying Dimensions and Constraints

Apply the necessary dimensions to the sketch using the dimensioning tool. Add geometric constraints such as horizontal, vertical, parallel, perpendicular and coincident constraints wherever required. This ensures that the sketch maintains the correct shape and measurements.
![image](https://user-images.githubusercontent.com/113594316/198551220-c7aa6694-4427-48e2-9d91-cd7e9615d651.png)

Step 7: Finishing the Sketch

After completing the 2D profile, carefully verify all the dimensions and geometrical features. Select the Finish Sketch option to complete the sketching process.

Step 8: Creating the 3D Solid Model

Select the Extrude command to convert the 2D sketch into a three-dimensional solid object. Enter the required extrusion distance based on the dimensions provided in the orthographic projection.
![image](https://user-images.githubusercontent.com/113594316/198551270-45875855-43a7-4471-af35-bd10cd9dd153.png)

Step 9: Adding Additional Features

Create the remaining features of the object using suitable modelling commands. Use the Extrude command to add material and create raised portions or steps. Use the required sketching tools to create additional profiles.

Step 10: Creating Holes and Slots

If the given object contains holes or slots, select the appropriate surface and create a sketch. Draw circles or rectangular profiles according to the given dimensions. Use the Cut or Hole command to remove the required material.
![image](https://user-images.githubusercontent.com/113594316/198551309-8d7ac6c8-6740-479f-8186-195c89823fda.png)

Step 11: Applying Fillet and Chamfer

Use the Fillet command to create rounded edges and the Chamfer command to create bevelled edges. Apply these operations wherever required by the given drawing.

Step 12: Modifying the Model

Use the available editing tools to modify the dimensions, positions and shapes of the features. Check whether all the parts of the model match the given orthographic projections.
![image](https://user-images.githubusercontent.com/113594316/198551340-fe1f3b48-df79-44ef-a4ae-ff1cd22503ea.png)

Step 13: Viewing the 3D Model

Use the View Cube or navigation tools to rotate the model and observe it from different directions, such as front, top, bottom, left, right and isometric views.

Step 14: Verifying the Model

Compare the final 3D model with the given front view, top view and side view. Check the overall dimensions, positions of holes, steps and other geometrical features. Make necessary corrections if any errors are found.
![image](https://user-images.githubusercontent.com/113594316/198551370-54509915-ec69-4862-9c17-156d61a83b11.png)

Step 15: Saving the Final Model

After completing the modelling process, save the final design using the appropriate file name and CAD file format. Generate the isometric view of the completed 3D model for clear visualization.
